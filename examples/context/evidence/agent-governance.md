# Evidence notes — Agent governance

Evidence ID: EV-AGENT-01

Use only these claims in this synthetic example:

1. Long-running agents accumulate context and tool outputs, so context selection and compression become operational concerns.
2. Agent systems need explicit boundaries around tools, permissions and consequential actions.
3. Evaluation should separate deterministic checks from semantic judgment when possible.
