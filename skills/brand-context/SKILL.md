# Brand Context

## Use when

A task depends on positioning, value proposition, messaging, voice, terminology or public claims.

## Workflow

1. Identify artifact and audience.
2. Locate canonical brand sources.
3. Load only relevant brand concepts.
4. Identify claims that require proof.
5. Keep examples separate from authority.
6. Return a compact context bundle.
7. Escalate unresolved strategic conflicts.

## Output

- task;
- audience;
- canonical positioning;
- relevant messages;
- voice constraints;
- terminology;
- proof dependencies;
- unresolved conflicts.
