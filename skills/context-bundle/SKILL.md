# Context Bundle

1. Identify the task and acceptance criteria.
2. Determine required domains.
3. Load canonical / approved sources first.
4. Exclude superseded or out-of-scope sources.
5. Respect the context budget.
6. Preserve source IDs in the bundle.
7. Emit an inclusion/exclusion manifest.
8. Do not convert a derived application into canonical truth.
